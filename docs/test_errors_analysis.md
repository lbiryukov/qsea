# Анализ ошибок в логах тестов (qsea_pytest.log)

## 1. KeyError: 'qNumFormat' (ИСПРАВЛЕНО)

**Файл:** `qsea/sheet_objects.py`, метод `ObjectMeasure.update()`

**Причина:** При обновлении меры в объекте на листе Qlik Sense возвращает структуру, где у мер с `numFormatFromTemplate: True` (библиотечные меры) в `qDef` отсутствует ключ `qNumFormat` — формат берётся из шаблона.

**Исправление:** Использовать `qdef.setdefault('qNumFormat', {})` перед обращением к полям формата.

---

## 2. MaxParallelSessionsExceeded

**Сообщение:** `Access to the app is denied: MaxParallelSessionsExceeded`

**Причина:** Превышен лимит параллельных сессий Qlik Sense Engine. Интеграционные тесты открывают много соединений к одному приложению.

**Рекомендации:**
- Уменьшить параллелизм тестов (pytest `-n 1` или `--maxprocesses=1`)
- Увеличить лимит сессий на сервере Qlik Sense (если есть доступ)
- Добавить задержки между тестами, использующими одно приложение
- Использовать `scope="session"` для connection и переиспользовать одно соединение

---

## 3. JSONDecodeError: Expecting value: line 1 column 1 (char 0)

**Причина:** Пустой ответ от WebSocket (сервер закрыл соединение или вернул не-JSON). Часто возникает вслед за `MaxParallelSessionsExceeded` — при отказе в подключении.

**Связь:** Каскадная ошибка после превышения лимита сессий.

---

## 4. WebSocketConnectionClosedException: Connection to remote host was lost

**Причина:** Соединение с Qlik Engine было разорвано (таймаут, перегрузка сервера, сетевая ошибка).

---

## 5. App "План-факт продаж(6)" is not found

**Причина:** Тест ожидает приложение с именем "План-факт продаж(6)", которого нет в списке приложений. Возможно, приложение переименовано, удалено или тест устарел.

**Рекомендация:** Обновить `MAIN_APP_NAME` или имя приложения в тестах, либо пропускать тест, если приложение недоступно.

---

## 6. Object.export_data failed: Invalid parameters

**Сообщение:** `sheet = Разные визуализации, id = 8350a777-28bc-4db2-9ec4-e797ef346863, file_type = csv, error: Invalid parameters`

**Причина:** Метод экспорта данных объекта получил некорректные параметры. Возможно, объект (фильтр/визуализация) не поддерживает экспорт в CSV в текущей конфигурации.

**Рекомендация:** Проверить тип объекта и поддерживаемые форматы экспорта в Qlik Engine API.

---

## 7. App not found (code 1003)

**Сообщение:** `OpenDoc method returned incorrect response. app_name = Qlik Engine Test, response = {'error': {'code': 1003, 'message': 'App not found'}}`

**Причина:** Временная недоступность приложения (например, после превышения лимита сессий приложение могло быть выгружено с сервера).

---

## Итог

| Ошибка | Тип | Действие |
|--------|-----|----------|
| qNumFormat KeyError | Баг в коде | Исправлено |
| MaxParallelSessionsExceeded | Инфраструктура/настройки | Ограничить параллелизм тестов |
| JSONDecodeError / Connection lost | Следствие лимита сессий | См. выше |
| App not found | Тестовые данные / окружение | Обновить конфигурацию тестов |
| export_data Invalid parameters | Возможный баг или несовместимость | Требует отдельной проверки |
